  TABLE 1: patients
  (Core patient profile — one row per patient)
════════════════════════════════════════════════════════════

  IDENTIFIER
  ──────────
  id                        INTEGER        Primary key, auto-increment

  PERSONAL INFORMATION
  ────────────────────
  lastName                  VARCHAR        e.g. "del Rosario"
  firstName                 VARCHAR        e.g. "Juniel"
  middleInitial             VARCHAR(2)     e.g. "B"
  age                       INTEGER        Age in years
  ageMonths                 INTEGER        Additional months (for infants)
  sex                       VARCHAR        "Male" | "Female"

  birthday                  DATE           Format: YYYY-MM-DD
                                           ⚠ UI validates via native date
                                           picker — stores "1993-03-15",
                                           NOT "March 15, 1993"

  religion                  VARCHAR        e.g. "Roman Catholic", "Islam"
  civilStatus               VARCHAR        "Single" | "Married" |
                                           "Widowed" | "Separated"

  contactNumber             VARCHAR(11)    ⚠ Digits ONLY, exactly 11
                                           characters (e.g. "09172345678").
                                           UI strips non-numeric input
                                           and enforces 11-digit length.

  educationalAttainment     VARCHAR        e.g. "College Graduate"
  occupation                VARCHAR        e.g. "Housewife", "Student"

  SPOUSE INFORMATION (optional — for married patients)
  ─────────────────────────────────────────────────────
  spouseName                VARCHAR        Full name of spouse
  spouseOccupation          VARCHAR        Spouse's occupation

  spouseContact             VARCHAR(11)    ⚠ Same validation as
                                           contactNumber — digits only,
                                           exactly 11 characters.

  ADDRESS
  ───────
  address                   VARCHAR        Street / Block / Lot
  purok                     VARCHAR        Purok name (local sub-area)
  barangay                  VARCHAR        e.g. "Gov. Paciano Bangoy"
  city                      VARCHAR        e.g. "Davao City"

  HEALTH PROGRAM
  ──────────────
  program                   VARCHAR        "Prenatal Care" |
                                           "Family Planning" |
                                           "National Immunization" |
                                           "National Tuberculosis" |
                                           "Cardiovascular Disease"
  familyPlanning            BOOLEAN        Enrolled in family planning
  vitamins                  BOOLEAN        Currently taking vitamins
  children                  INTEGER        Number of children

  MEDICAL / CLINICAL INFORMATION
  ───────────────────────────────
  coMorbidities             VARCHAR / TEXT ⚠ Now sourced from multi-select
                                           checkboxes in the UI. Stored as
                                           a comma-separated string of
                                           selected conditions, or "None".
                                           Adult checkbox options:
                                             Hypertension | Diabetes |
                                             STI/HIV | Heart Disease |
                                             Kidney Failure | TB
                                           Patients ≤ 5 yrs: only
                                           Allergies & Cancer shown.

  cancer                    VARCHAR        ⚠ NEW FIELD (added with UI
                                           changes). Dropdown in UI:
                                           "None" OR free-text string
                                           (e.g. "Breast Cancer").
                                           Store "None" when not applicable.

  allergies                 VARCHAR        Dropdown in UI:
                                           "None" OR free-text string
                                           (e.g. "Penicillin, Aspirin").
                                           Store "None" when not applicable.

  maintenanceMedication     TEXT           Current maintenance medications,
                                           dose & frequency (free text)
  previousIllnesses         TEXT           Past illnesses / surgeries
                                           (free text)

  LATEST VITALS
  ─────────────
  lastVisit                 DATE           Format: YYYY-MM-DD
                                           ⚠ UI validates via native date
                                           picker — stores "2026-02-14",
                                           NOT "February 14, 2026"

  bloodPressure             VARCHAR        ⚠ Format enforced: "X/Y mmHg"
                                           UI shows editable numeric part
                                           + locked "mmHg" suffix badge.
                                           e.g. "120/80 mmHg"

  weight                    VARCHAR        ⚠ Format enforced: "X kg"
                                           UI shows editable number + locked
                                           "kg" suffix badge.
                                           e.g. "58 kg"

  height                    VARCHAR        ⚠ Format enforced: "X cm"
                                           UI shows editable number + locked
                                           "cm" suffix badge.
                                           e.g. "155 cm"

  NEWBORN VACCINES (at birth)
  ───────────────────────────
  bcgVaccine                VARCHAR        "YES" | "NO" | "N/A"
  hepBVaccine               VARCHAR        "YES" | "NO" | "N/A"
  vitaminK                  VARCHAR        "YES" | "NO" | "N/A"

  FAMILY HISTORY
  ──────────────
  familyHistoryConditions   TEXT / JSON    Array of conditions:

                                           "Birth Defects" | "Cancer" |

                                           "Hypertension" | "Lung Disease" |
                                           "Mental Illness"
  familyHistoryOther        TEXT           Free-text other conditions
  familyHistoryMother       VARCHAR        "YES" | "NO" | "N/A"

  ARCHIVE STATUS
  ──────────────
  isArchived                BOOLEAN        Whether patient is archived
  archivedAt                TIMESTAMP      When the patient was archived

════════════════════════════════════════════════════════════
  TABLE 5: logbook_entries
  (Audit trail of all staff actions on patient records)
════════════════════════════════════════════════════════════

  id                        INTEGER        Primary key, auto-increment
  staffUsername             VARCHAR        FK / ref → staff_accounts.username
  action                    VARCHAR        "Add Record"    — new patient registered
                                           "Edit Record"   — patient record updated
                                           "Delete Record" — hard-deleted
                                           "Archive"       — moved to archive
                                           "Restore"       — restored from archive
  patientName               VARCHAR        Full name snapshot at time of action
  patientId                 INTEGER        FK → patients.id (optional reference)
  timestamp                 TIMESTAMP      Date and time of action
                                           (auto-set by addLogbookEntry() service)

  ⚠ API SERVICE NOTE:
    addLogbookEntry() was added to logbook.service.ts.
    It must be called manually from components after every:
      - createPatient()   → action: "Add Record"
      - updatePatient()   → action: "Edit Record"
      - deletePatient()   → action: "Delete Record"
      - archivePatient()  → action: "Archive"
      - restorePatient()  → action: "Restore"
